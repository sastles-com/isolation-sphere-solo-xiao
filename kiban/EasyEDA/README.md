# Isolation Sphere 電源システム — 基板A / 基板B

## 目的

次期 Isolation Sphere 電源システムの基本アーキテクチャを定義する。
別の LLM / 技術者がチャット履歴から判断を再構成せずに、EasyEDA で回路図と PCB を実装できるようにするためのパッケージである。

2026-10-07、本パッケージを電源系の正式案として採用した。
`kiban/power-2s`（IP2326 + MP1584、5V LED）は参考資料扱いとする。

設計は意図的に、40 mm × 40 mm の基板2枚を重ねる構成としている。

- **基板A — システム電源 / mother-ring インターフェース**
- **基板B — 電池 / 充電 / BMS**

基板Aは上側で MCU / 北極側を向く。基板Bは下側で LiPo パックを向く。

## システム要件

- 電池：**2S LiPo、2000 mAh × 2 直列**
  - 公称電圧：7.4 V（`VSYS` の公称値もこれに従う）
  - 満充電：8.4 V
  - 容量は 2000 mAh のまま（公称約 14.8 Wh）
- 充電入力：**南極のマグネット充電端子から 5 V**（9 V / 12 V への変更を検討中。`docs/hardware_spec.md` §3）
- 充電中の動作：**必須**
- 表示：アドレス指定型 LED 約 800 個
- 使用 LED：**WS2812C-2020-V6**（確定）を **3.3 V LED レール**で駆動
- LED レール：**想定 3 A、システムとして 4 A を確保。変換器は余裕のある品種を選ぶ**
- MCU レール：独立した **3.3 V レール**、**1〜2 A クラス**
- MCU：北極付近の別基板上の ESP32-S3（XIAO ESP32S3）
- 主制御バス：MCU 側からの I²C
- 基板サイズ：**各 40 mm × 40 mm**
- 基板Aは両面実装可
- **core 基板（北極側の MCU 基板）と電源基板（基板A）は、スペーサー経由でねじ止めする。四隅の4点すべてで固定し、対角の2組（左上–右下、右上–左下）の両方を使う**（`docs/hardware_spec.md` §1.3）
- **基板Bの裏面は部品禁止**（LiPo パウチに面するため）
- 基板Bと LiPo の間に電気的・機械的な絶縁フィルムを挟む
- LiPo 側の面では、突起・露出パッド・鋭い基板角・不要な露出ビアを避ける

## 現在の基本アーキテクチャ

### 基板A — システム電源

mother-ring へ配る電源レールを生成し、電源 ON/OFF 制御を行う。

主な機能：

- LTC2954-1 電源 ON/OFF コントローラ
- 北極ホール起動センサ用の常時オン低 Iq レギュレータ
- LED 用 3.3 V 降圧コンバータ（4 A 必須、5〜6 A クラス推奨）
- MCU 用 3.3 V 降圧コンバータ（1〜2 A クラス）
- mother-ring との接続：1×6、2.54 mm コネクタ 2 個
- ESP32 からの `LED_EN` で LED 降圧を制御
- MCU 降圧は LTC2954 が制御
- ESP32 からの `PWR_KILL` で通常シャットダウン
- DRV5032FC からの `HALL_WAKE` で起動 / ハードウェア長押しを行う

### 基板B — 電池 / 充電 / BMS

2S LiPo と充電インターフェースに直結する。

主な機能：

- BQ25883 2S 充電 / パワーパス IC（12 V 入力にする場合は BQ25798 へ変更を検討）
- BQ28Z610-R1 1〜2S 残量計 + パック保護 + セルバランス
- BQ28Z610-R1 リファレンス設計どおりの外付け保護 FET と電流検出シャント
- 2S 電池接続：B+、セル中点（BM）、B−
- 南極マグネット充電端子からの充電入力
- 基板Aへの保護済み / システム電池出力
- 基板A / mother-ring 経由で ESP32 と I²C 接続

### 置き換え対象の旧モジュール

以下は現行 / 旧ハードウェアのもので、**新設計の基本構成ではない**。

- IP2326 充電モジュール
- XR-2S-30A BMS 基板
- MP1584 5 V 変換モジュール
- MAX16054 電源スイッチコントローラ
- MAX17049 残量計

実績のある動作や特性は検証時の参考にしてよいが、新設計はゼロベースで行う。

## 北極のデバイス

北極には以下がある。

- **DRV5032FC**：常時オンのデジタルホールスイッチ（全極性・オープンドレイン・20 Hz）。電源 ON と、LTC2954 へのハードウェア長押し経路に使う。
- **TMAG5273**：3 軸 I²C ホールセンサ。システム ON 中のみ使用し、コマンドと通常の電源 OFF ジェスチャを検出する。
- **WS2812C-2020-V6 ×1**：**表示インジケータではない**。北極の表示用 LED で、`line05` の 161 番目の LED。
- 任意の小型インジケータ LED：ホール / コマンドの受付表示のためだけに追加してよい。OFF 中に動作する必要は**ない**。

## 電源制御の動作

### 電源 ON

1. システムは OFF。
2. DRV5032FC は `3V3_AON` で常時動作している。
3. 北極に磁石を近づけて保持する。
4. LTC2954 が長押し（約 2 秒）を確認し、MCU 降圧を有効にする。
5. ESP32-S3 が起動する。
6. 表示電源が必要になった時点で、ESP32 が明示的に `LED_EN` をアサートする。

ON のために近づけた磁石を保持し続けても、OFF 操作とは扱わない。LTC2954 は起動後 512 ms は PB を無視し、その後は「一度離してから再び押す」ことで初めて OFF シーケンスを開始する。

### 通常の電源 OFF

1. システムは ON。
2. TMAG5273 が意図した OFF ジェスチャ / 保持を検出する。
3. ESP32 がジェスチャを解釈する。
4. ESP32 が最初に `LED_EN` をデアサートする。
5. ESP32 が必要な状態保存 / 終了処理を行う。
6. ESP32 が `PWR_KILL` を Low にして LTC2954 へ伝える。
7. LTC2954 が MCU システム電源を切る。

### 強制 OFF

ESP32 がハングしていても、磁石を十分長く保持すれば、LTC2954 の独立したハードウェアタイマでシステム電源を強制的に切れなければならない。

タイミングは LTC2954 データシートの式から以下とする（詳細は `docs/hardware_spec.md` §5）。

| 操作 | コンデンサ | 公称 | 部品ばらつき込みの範囲 |
| --- | --- | ---: | ---: |
| ON 長押し | C_ONT = 0.33 µF | 約 2.15 s | 約 1.5〜2.8 s |
| 強制 OFF 長押し | C_PDT = 1.2 µF | 約 7.8 s | 約 5.5〜10 s |

正式リリース前に実機で確認する。

## mother-ring 接続

基板Aには mother-ring と接続する **1×6、2.54 mm コネクタ**が左右に1個ずつある。

論理ピン割り当ては `docs/interfaces.md` にまとめている。

最大約 4 A の LED 電流が 1 本のピンに集中しないよう、LED 電源は左右の2系統に分けて給電する。

## 実装状況

アーキテクチャと各基板の役割は、回路図作成を始められる程度に確定している。ただし、部品レベルではまだ最新のデータシートとリファレンス設計との照合が必要な項目がある。それらは `docs/handoff.md` と `docs/hardware_spec.md` にまとめている。

回路図、パワーパス構成、保護構成、ピン割り当て、EasyEDA ライブラリ部品のレビューが終わるまで、製造用ファイルは作らない。
