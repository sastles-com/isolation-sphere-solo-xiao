## 2. 充電部（BQ25792）

## 3. 保護部（BQ28Z620）

TI の BQ28Z620 データシート Figure 10-1（2 直列）と、BQ28Z620EVM（SLUUCQ5）の部品表より。

構成：

- 保護 FET 2 個（充電用と放電用）を、セルのプラス側（高い側）に、向かい合わせに直列で入れる。ゲートは `CHG`（9 番）と `DSG`（7 番）から駆動する。
- 電流検出のシャントは、セルのマイナス側（低い側、`PACK−` との間）に入れる。`SRP` と `SRN` に各 100 Ω + 0.1 µF のフィルタ。
- `VC2`：スタック全体（BAT）の測定と電源。`VC1`：セル 1 とセル 2 の中点。各 100 Ω + 0.1 µF。`PBI` は 2.2 µF → GND。
- `PACK`（8 番）：パック電圧の測定。10 Ω を通して `PACK+` へ。
- `TS1`（4 番）：10 kΩ NTC（103AT-2）。
- `SCL`、`SDA`：100 Ω の直列抵抗と、5.6 V ツェナー（MM3Z5V6C）で保護。

EVM の部品表（抜粋）：

| 部品 | 値・型番 |
| --- | --- |
| 保護 FET（Q2、Q3） | CSD16412Q5A（Nch、30 V、SON 5×6） |
| シャント（R24） | 1 mΩ、1206（CSNL1206FT1L00）。データシートの推奨範囲は 1〜3 mΩ |
| NTC（RT1） | 10 kΩ（103AT-2） |
| 二次保護 IC（U1） | BQ294502DRV（過電圧の最大値 4.35 V） |
| ヒューズ溶断回路 | Q1（SI1416EDH）と Q4（2N7002K）、10 MΩ × 2 |
| ツェナー | MM3Z5V6C × 2（`SCL`、`SDA` 用） |
| 抵抗 | 100 Ω × 8、5.1 kΩ × 4、10 MΩ × 2 ほか |

EVM の電流定格は、BQ28Z620 の設計例で 6 A（過電流の閾値）。本設計の電池電流は最大約 3 A なので、シャントは 2 mΩ 前後でも足りる。値は、測定の精度と損失（3 A で 3 mΩ なら 27 mW）で決める。

## 4. 決める必要があること（描く前に）

1. **二次保護（BQ294502）とヒューズを入れるか。** EVM はセルのプラス側に化学ヒューズを入れ、BQ294502 が過電圧時にヒューズを溶断する構成。BQ28Z620 が故障したときの最後の砦になる。入れる場合は、ヒューズ（3 A 以上、セルの電流を流せるもの）と、溶断回路の部品が増える。**推奨：入れる。** 電池が 2 個あるので、各セルに入れるか、スタックに 1 個入れるかも決める。
2. **電池に付属の保護基板（PCM）があるか。** LiPo にはコネクタが付いていないとのことだが、保護回路も付いていないか確認する。付いている場合は、保護が二重になる。
3. 保護 FET の選定：CSD16412Q5A は LCSC での入手性が不明。3 A に対しては大きすぎるので、小型の Nch FET（デュアル、30 V 以下、Rds(on) 20 mΩ 以下、小さいパッケージ）を探す。BQ28Z620 の `CHG`、`DSG` の駆動電圧（5.75 V または 9.4 V）で完全にオンになるものにする。
4. 充電 IC の `BAT` を、保護 FET の**パック側**（`PACK+`）につなぐ構成でよいか。保護 FET が開いたとき、充電も放電も止まる。
5. 基板Bの `VSYS` の出力は、充電 IC の `SYS` から出す。

## 5. 描く順序（案）

1. 充電部（BQ25792）：§2 の値で。部品の LCSC 番号を決めてから配置する。
2. 保護部（BQ28Z620）：§4 の決定後。
3. 電池コネクタ（XH 2P × 2）、基板A との接続（ピンヘッダ 1×6 × 2）、テストポイント。
