## 断面が「島状」になるとは

コアを z 一定の平面で切ると、断面は 1 本の輪ではなく、円周に沿って並んだ**ばらばらの小さな塊**になる（`outputs/fit/section_z*.svg` の黒い線）。
塊は柱やボス（ねじ止め用の突起）で、塊と塊のあいだは空いている。さらに左右（±x）には、U 字の溝や四角い塊がある。

そのため、基板やセルが収まるかは、「軸から最も近い塊までの距離」ではなく、**塊の一つひとつに当たるか**で調べる必要がある。
