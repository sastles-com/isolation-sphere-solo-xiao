# mother-ring 改版の要件書（案）

新しい電源基板（基板A / 基板B）に合わせて mother-ring を改版するための要件書。回路図・PCB はまだ触らない。
現状の調査元は `FPC-isolation-sphere/kiban/mother-ring-03`（KiCad、2 層、1.6 mm）と、MCU 基板 `core-XIAO-03`。

状態：**案**。§6 の未決事項が決まるまで、回路図の改版は始めない。

## 0. 確定した方針（ユーザー決定、2026-10-10）

1. **LED への給電は 3.3 V（`3V3_LED`）**。mother-ring 上の `+5V` はすべて `3V3_LED` に置き換える。
2. **J6〜J9 は位置と配線の内容が変わる**。新しい基板A・MCU 基板に合わせて、4 個とも作り直す（§3.1、§3.3）。
3. **南北への導線のアクセスを考えて、穴の配置を再考する**（§3.5）。
4. **内部コアまわりは再設計する**。mother-ring の外形・穴・取付位置は、新しいコアに合わせて決める（§3.6）。

赤道面にある円盤状の基板（外径 88 mm）。座標は KiCad の上面図（x 右、y 下、単位 mm）。

## 2. 新しい基板とのずれ

### 2.1 基板A 側（現 J6、J7）

基板A（`kicad/boardA/boardA.kicad_pcb`）の mother-ring 用ヘッダ：

| 基板A | 位置（基板A 上面図） | ピン 1 → 6（y = +6.35 → −6.35） |
| --- | --- | --- |
| J1 MOTHER LEFT | x = −21.59 | `3V3_LED` / `GND` / `3V3_MCU` / `I2C_SDA` / `I2C_SCL` / `3V3_AON` |
| J2 MOTHER RIGHT | x = +21.59 | `3V3_LED` / `GND` / `GND` / `HALL_WAKE` / `PWR_KILL` / `LED_EN` |

- **位置**：左右のヘッダの間隔が 45.08 mm（ring の J6–J7）から 43.18 mm（基板A の J1–J2）に変わった。片側 0.95 mm ずつ内側。
- **向き**：基板A の外形は 40 mm 角に左右の張り出し（x = ±25、y = ±9.25）。`fit_check.py` の結果では、現在のコアでは張り出しを殻の ±y 方向に向けないと収まらない。ring 上でのヘッダの方位は、新しいコアでの基板A の向きに合わせて決める（§3.6）。
- **配線**：割り当ては全面的に変わる（`interfaces.md` §2）。

### 2.2 MCU 基板側（現 J8、J9）

core-XIAO-03 のヘッダ（core の上面図）：

| core-XIAO-03 | 位置 | ピン 1 → 6（y = +6.35 → −6.35） |
| --- | --- | --- |
| J2 ESP32-01 | x = −22.54 | `PGND` / `VIN` / `SCL` / `SDA` / `PGND` / `3V3` |
| J4 ESP32-02 | x = +22.54 | `AGND` / `GPIO01`〜`GPIO04` / `GPIO09` |

- 信号が変わる：`ESP-VIN`（5 V）は `3V3_MCU` に、さらに `PWR_KILL`、`LED_EN` が増える（§3.3）。
- **要確認**：ring の J8 と core の J2 を、電源ピン（`GND`、`VIN`、`3V3`）がそろう向きで重ねると、`SDA` と `SCL` の位置が入れ替わって見える。実機で動いているなら、ファームの I²C ピン指定で吸収している可能性がある。改版では、ring と MCU 基板でピン名と位置を一致させる。
- core 側の 6 番ピンのネット名 `GPIO09` は、ring 側では `GPIO05`（`xiao_bringup.md` の暫定ピンの件）。名前をそろえる。

## 3. 改版の要件

### 3.1 基板A 側のヘッダ（新 J6、J7）

1. 基板A の J1、J2 と同じ位置（間隔 43.18 mm、1×6、2.54 mm）に置く。
2. ピン割り当ては §2.1 の表と同じネットにする。ring と基板A が向かい合っても、同じ位置のピンが同じネットになるよう、**ring の F.Cu が北を向く前提で座標を合わせ、1 番ピンの位置を図で確認する**。
3. `3V3_LED` は左右 1 本ずつ、それぞれ約 2 A。コネクタ（秋月 PH-1x40SG、3 A / ピン）の範囲内だが、温度上昇と接触抵抗は実測で確認する。
4. `GND` はすべて同じネット。

### 3.2 LED ストリップ（J1〜J5）

1. 1 番ピンと 6 番ピンを `3V3_LED` に変更し、5 本へ分配する。
2. データ線は `GPIOn` → 33 Ω → `DINn` を維持する。LED の VIH は 0.55 × VDD（3.3 V 時に約 1.8 V）なので、3.3 V の GPIO で駆動できる。
3. `DOUT05` に端子を新設し、北極の LED（161 番目）へ延ばす。

### 3.3 MCU 基板側のヘッダ（新 J8、J9）

MCU 基板（core-XIAO-04 仮）と同時に決める。必要な信号：

| 信号 | 方向 | 備考 |
| --- | --- | --- |
| `3V3_MCU` | ring → MCU | 給電（§6-1） |
| `GND` | 共通 | |
| `I2C_SDA` / `I2C_SCL` | 双方向 / MCU → | 100 kHz で立ち上げる |
| `GPIO01`〜`GPIO05` | MCU → ring | LED データ 5 本 |
| `PWR_KILL` | MCU → ring → 基板A | 起動中に Low を出さない（FW-1） |
| `LED_EN` | MCU → ring → 基板A | `LED_EN` が Low の間はデータ線も Low（FW-2） |

GND を除いて 10 本。2 個の 1×6 に収まる。割り当て案は §6-2。

### 3.4 北極・南極への導線

北極へ延ばす線：

| 線 | 用途 |
| --- | --- |
| `3V3_AON` | DRV5032FC |
| `HALL_WAKE` | DRV5032FC → ring → 基板A の LTC2954 PB（MCU 基板を経由しない） |
| `3V3_MCU`、`I2C_SDA`、`I2C_SCL` | TMAG5273 |
| `3V3_LED`、`DOUT05` | 北極の LED（161 番目） |
| `GND` | |

計 8 本（GND 1 本の場合）。現状の pillar 配線は 6 本。

南極側：充電入力は基板B が直接受けるため、ring を通す線はない見込み（§6-4 で確認）。

### 3.5 穴の配置（§0-3）

1. 北極へ行く線（§3.4）を、ring のどこを通すかを先に決める。組み立て時に、線を通す・抜く・はんだ付けする作業ができる位置と大きさにする。
2. 現状の外周付近の Ø3.2 穴 19 個と Ø2.8 穴 4 個の用途を確認し、残すもの・移すものを決める。
3. 新しい J6〜J9（§3.1、§3.3）、LED コネクタ J1〜J5、コアへの取付穴と干渉しないこと。
4. 中央の切り欠き（セル用）の形状を、3D データで整理する。

### 3.6 内部コアとの関係（§0-4）

- 内部コアは再設計する。ring の外形、中央の切り欠き、取付穴、ヘッダの方位は、新しいコアの寸法が決まってから確定する。
- コアへの要求として出すもの：
  - 基板A の向き（張り出しの方向）と、ring 上のヘッダの方位の関係
  - 北極・南極への線の通り道（コア側の溝や穴と、ring の穴の位置をそろえる）
  - 北のセル（40×40×10）の干渉の解消（`fit_report.md`：現在のコアでは一辺 39.5 mm 以下でないと当たる）
- 再設計後に `fit_check.py` で収納を確認する。

### 3.7 削除するもの

- 充電・電池系（`CHARGE`、`BM`、`P+`、J10、J14）。
- 5 V 系（J11、J12、J15、`5V-ALWAYS`、FB1）。
- J13（`+3V3` の取り出し）は、`3V3_MCU` の確認用に残すかを決める。

## 4. 電気的な見積り（要確認）

- LED 電流は合計 4 A 以下に制限する（ファーム）。ring には最大 4 A、左右のヘッダで 2 A ずつ流れる。
- 現状の ring は 2 層。`3V3_LED` と `GND` は幅の広い配線かベタにする。4 層にするかも検討する。
- LED 降圧の出力は 3.4〜3.5 V に上げる前提（`hardware_spec.md`「電圧降下の余裕がない」）。ring 上で許す電圧降下を決め、配線幅を決める。
- ストリップごとのバルクコンデンサを ring に置くかを決める（各 LED の 100 nF は FPC 側）。

## 5. 作業の順番

1. 内部コアの再設計の方針（寸法、基板A の向き、線の通り道）を決める。
2. MCU 基板（core-XIAO-04）のヘッダ位置と割り当てを決める。
3. §6 の未決事項を決める。
4. mother-ring-03 を `mother-ring-04` として複製し、回路図（コネクタ、LED 電源、削除部品）を改版する。
5. 外形・穴・ヘッダ位置を新しいコアに合わせ、配線し直す。DRC と `fit_check.py` で確認する。

## 6. 未決事項

1. **MCU 基板への給電**：旧設計は 5 V（`ESP-VIN`）を XIAO に入れていた。新設計の `3V3_MCU`（3.3 V）を XIAO のどのピンに入れるか。XIAO の仕様書で、3.3 V を外から入れたときの内蔵レギュレータとの関係を確認する。
2. **J8 / J9 の割り当て案**（MCU 基板とそろえる）：

   | ピン | J8 | J9 |
   | ---: | --- | --- |
   | 1 | `GND` | `GND` |
   | 2 | `3V3_MCU` | `GPIO01` |
   | 3 | `I2C_SDA` | `GPIO02` |
   | 4 | `I2C_SCL` | `GPIO03` |
   | 5 | `PWR_KILL` | `GPIO04` |
   | 6 | `LED_EN` | `GPIO05` |

   GND が 2 本に減ることを許容できるか。
3. ring の F.Cu が北と南のどちらを向くか（ヘッダの 1 番ピンの位置合わせに必要）。
4. 南極側に ring を通す線があるか（充電の検出線など）。
5. 北極への線の本数（GND を複数にするか）と、ring 上の端子の形（ヘッダ、パッド、コネクタ）。
6. ring 上で許す電圧降下と、2 層 / 4 層。
7. 基板A / core 基板の浮き・抜け対策（別途対応済み）に合わせて、ring 側に必要な変更があるか。
8. 作図ツール：KiCad のまま改版するか、EasyEDA Pro に移植するか。
9. 現状の SDA / SCL の入れ替わり（§2.2）が意図したものか。
