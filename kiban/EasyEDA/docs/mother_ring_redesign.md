# mother-ring 改版の要件書（案）

新しい電源基板（基板A / 基板B）に合わせて mother-ring を改版するための要件書。回路図・PCB はまだ触らない。
現状の調査元は `FPC-isolation-sphere/kiban/mother-ring-03`（KiCad、2 層、1.6 mm）。

状態：**案**。「未決事項」（§5）が決まるまで、回路図の改版は始めない。

## 1. 現状（mother-ring-03）

| J6 | POWER-01 | 2.54 mm ヘッダ 1×6（x = −22.54, y = −6.35） | `GND` / `+5V` / `+5V` / `5V-ALWAYS` / `5V-ALWAYS` / `GND` | 旧電源基板（5 V）との接続 |

| 電源側コネクタ J7 | 充電・電池系 | 右：`3V3_LED_R` / `GND_R` / `GND_SYS` / `HALL_WAKE` / `PWR_KILL` / `LED_EN` | 同上。`CHARGE` / `BM` / `P+` は不要 |

## 3. 改版の要件

### 3.1 コネクタ

1. 基板A に向く 2 個の 1×6 ヘッダ（現 J6、J7）を、`interfaces.md` §2 のピン割り当てに合わせる。**基板A とは上下が向かい合うので、1 番ピンの位置が鏡像になる**。回路図を直す前に、基板A のフットプリントとの対応（左右・1 番ピンの向き）を確認する（§5-3）。
2. 大電流の `3V3_LED_L` と `3V3_LED_R` は、それぞれ 1 本のピンに約 2 A（合計 4 A）を流す。コネクタの定格（秋月 PH-1x40SG、3 A / ピン）の範囲だが、温度上昇と接触抵抗を実測で確認する。
3. `GND_L` / `GND_R` / `GND_SYS` は ring 上ではすべて同じ `GND`。

### 3.2 LED ストリップ（J1〜J5）

1. 1 番ピンと 6 番ピンを `+5V` から `3V3_LED` に変更する。5 本のストリップへ分配する。
2. データ線は `GPIOn` → 33 Ω → `DINn` を維持する。LED の VIH は 0.55 × VDD（3.3 V 時で約 1.8 V）なので、3.3 V の GPIO を直接受けられる。
3. `DOUT05` に端子を新設し、北極の LED（161 番目）へ延ばす。北極側の電源は `3V3_LED`。
4. FPC 側のストリップ基板が 5 V 前提の部品を含んでいないか確認する（§5-5）。

### 3.3 MCU 基板側（J8、J9）

MCU 基板に渡す信号は次のとおり。

| 信号 | 方向 | 備考 |
| --- | --- | --- |
| `3V3_MCU` | ring → MCU | 給電（§5-1） |
| `GND` | 共通 | |
| `I2C_SDA` / `I2C_SCL` | 双方向 / MCU → | 100 kHz で立ち上げる |
| `GPIO01`〜`GPIO05` | MCU → ring | LED データ 5 本 |
| `PWR_KILL` | MCU → ring | 起動中に Low を出さない（FW-1） |
| `LED_EN` | MCU → ring | LED が Low の間はデータ線も Low（FW-2） |

必要な信号は GND を除いて 10 本。12 ピン（J8 + J9）に収まるが余裕は少ない。割り当ての案は §5-2。

### 3.4 北極への配線

- `3V3_AON`（DRV5032FC）、`3V3_MCU`、`I2C_SDA`、`I2C_SCL`（TMAG5273）、`3V3_LED`、`DOUT05`、`HALL_WAKE`、`GND` を北極へ延ばす。
- `HALL_WAKE` は北極 → ring → 基板A の LTC2954 PB の経路になる。MCU 基板を経由しない。
- 線の本数は、現状の pillar 配線 6 本から増える（`xiao_bringup.md` は 8 本と想定）。上の信号をすべて通すと 8 本を超えるので、本数を決める（§5-4）。

### 3.5 削除するもの

- 充電・電池系（`CHARGE`、`BM`、`P+`、J10、J14）。
- 5 V 系の取り出し（J11、J12、J15、`5V-ALWAYS`、FB1 とその周辺）。
- J13（`+3V3` の取り出し）は、`3V3_MCU` の取り出し口として残すかを決める。

## 4. 電気的な見積り（要確認）

- LED 電流は合計 4 A 以下に制限する（firmware）。ring には最大 4 A が流れ、左右のヘッダで 2 A ずつに分かれる。
- 現状の ring は 2 層。LED 電流の経路は幅の広い配線か、ベタに近い銅箔にする。
- `hardware_spec.md` の「電圧降下の余裕がない」にあるとおり、LED 降圧の出力は 3.4〜3.5 V に上げる前提。ring 末端の電圧は、配線抵抗とコネクタ抵抗を実測してから決める。ring 側の許容降下の予算を決めること（§5-6）。
- 各 LED の VDD に 100 nF（`hardware_spec.md`）は FPC 側の設計事項。ring には、ストリップごとの電解またはセラミックのバルクコンデンサを置くかを決める。

## 5. 未決事項

1. **MCU 基板への給電**：旧設計は 5 V（`ESP-VIN`）を XIAO に入れていた。新設計は 3.3 V の `3V3_MCU` なので、XIAO のどのピンに入れるか、内蔵の降圧との関係を確認する（XIAO の仕様書で確認）。MCU 基板（core-XIAO-04 仮）の設計と一緒に決める。
2. **J8 / J9 のピン割り当て案**（MCU 基板の改版とそろえる）：

   | ピン | J8 | J9 |
   | ---: | --- | --- |
   | 1 | `GND` | `GND` |
   | 2 | `3V3_MCU` | `GPIO01`（LED データ 1） |
   | 3 | `I2C_SDA` | `GPIO02` |
   | 4 | `I2C_SCL` | `GPIO03` |
   | 5 | `PWR_KILL` | `GPIO04` |
   | 6 | `LED_EN` | `GPIO05` |

   `GND` が 2 本に減る点と、`+3V3` の取り出しがなくなる点を許容できるか。
3. 基板A の左右のヘッダと、ring の J6 / J7 の対応（どちらが左か、1 番ピンの向き、鏡像）。基板A の KiCad（`kicad/boardA`）で確認する。
4. 北極への線の本数と、コネクタ形状（pillar 配線）。
5. FPC ストリップ（`FPC-half-gore` 等）が 3.3 V 給電で問題ないか。LED は WS2812C-2020（VDD 3.3〜5.3 V）だが、バイパスコンデンサや他の部品の耐圧を確認する。
6. ring 上での電圧降下の許容値。
7. 基板の固定：基板A / core 基板の浮き・抜け対策（別途対応済み）に合わせて、ring 側に必要な変更（取付穴など）があるか。
8. コア内殻の再設計（`easyeda_workflow.md` §5.6）に合わせた外形の変更が要るか。
9. 作図ツール：KiCad のまま改版するか、EasyEDA Pro に移植するか（`easyeda_workflow.md` §1、現状は未決。EasyEDA Pro のブリッジが必要）。
