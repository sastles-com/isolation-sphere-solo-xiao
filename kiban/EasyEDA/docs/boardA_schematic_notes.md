## 3. 回路の要点

### 3.1 電源 ON/OFF（U3 LTC2954-1）

| ピン | 接続 |
| --- | --- |
| VIN | `VSYS`（0.1 µF） |
| PB# | `HALL_WAKE` → 5.1 kΩ → `PB_F`、`PB_F`–GND に 0.1 µF（長い配線のため。LTC2954 データシートの推奨） |
| ONT | 0.33 µF（C159798）→ ON 長押し 約 2.15 s |
| PDT | 1 µF + 0.22 µF（並列 1.22 µF）→ 強制 OFF 約 7.9 s |
| KILL# | `PWR_KILL`。`3V3_MCU` へ 100 kΩ でプルアップ（ESP32 のリセット中も電源を保つ） |
| EN | `MCU_EN` → U5 の `EN` に直結 |
| INT# | `PWR_INT` → テストパッド（任意） |

**U5 の `EN` を `VSYS` にプルアップしてはいけない。** TPS62933 の `EN` の絶対最大は 6 V。U5 の `EN` には内部プルアップ（0.7 µA）があり、開放で ON になる。LTC2954-1 の `EN` が L に引くと OFF。OFF 中の電流は 0.7 µA だけ。

### 3.2 常時オン 3.3 V（U4 TPS70933）

`IN` と `EN` を `VSYS` に。入力 1 µF、出力 2.2 µF。`3V3_AON` は北極の DRV5032FC だけに給電する（mother-ring の J_ML 6 番）。

### 3.3 MCU 用 3.3 V（U5 TPS62933）

- `RT` を GND：1.2 MHz
- 出力 = 0.8 V × (1 + 31.6 kΩ / 10 kΩ) = 3.33 V
- インダクタ 2.2 µH（SWPA4030S2R2NT、C279948、4 × 4 mm）。TI の推奨（1.2 MHz で 2.2 µH、実効 30 µF）
- 出力 22 µF × 2（C45783、0805 10 V）、入力 10 µF + 0.1 µF、ソフトスタート 10 nF（6.8 nF 以上が必須）、ブートストラップ 0.1 µF

### 3.4 LED 用 3.3 V（U6 TPS566238P）

- 出力 = 0.6 V × (1 + 93.1 kΩ / 20 kΩ) = **3.39 V**。WS2812C-2020-V6 の下限 3.3 V に余裕を持たせた。実測後に 93.1 kΩ を変えて調整する（3.46 V にするなら 95.3 kΩ）
- フィードフォワード 47 pF（TI の推奨 10〜100 pF）
- インダクタ 2.2 µH（SPM6530T-2R2M、C76855、7.1 × 6.5 mm）。TI の推奨は 1.5〜4.7 µH
- 出力 22 µF × 4、入力 10 µF × 3 + 0.1 µF、`VCC` 1 µF、ブートストラップ 0.1 µF
- `EN` = `LED_EN`、GND へ 100 kΩ（MCU が起動するまで OFF）
- `PG` = `L_PG` → テストパッド（任意）
- 電流：電池電流 2 A 制限のため、LED は最大 約 3.6 A（`interfaces.md` FW-2）

### 3.5 プルアップ（`3V3_MCU`、基板A に集約）

| ネット | 値 |
| --- | --- |
| `I2C_SDA`、`I2C_SCL` | 4.7 kΩ |
| `CHG_INT`（BQ25792 の INT） | 10 kΩ |
| `PWR_KILL` | 100 kΩ（POWER ページ） |

`3V3_MCU` は電源 OFF 中に 0 V なので、基板B の IC へプルアップを通じて逆給電しない。

### 3.6 コネクタ

| 記号 | ピン 1〜6 |
| --- | --- |
| J_ML（mother-ring 左） | `3V3_LED` / `GND` / `3V3_MCU` / `I2C_SDA` / `I2C_SCL` / `3V3_AON` |
| J_MR（mother-ring 右） | `3V3_LED` / `GND` / `GND` / `HALL_WAKE` / `PWR_KILL` / `LED_EN` |
| J_BA1（基板B 電源） | `VSYS` × 3 / `GND` × 3 |
| J_BA2（基板B 信号） | `I2C_SDA` / `GND` / `I2C_SCL` / `CHG_INT` / NC / `GND` |

`interfaces.md` の `3V3_LED_L` / `3V3_LED_R` は `3V3_LED`、`GND_L` / `GND_R` / `GND_SYS` は `GND` として 1 つのネットにした。

## 4. 確認・未決事項

1. **L3（SPM6530T-2R2M）の飽和電流**：U6 の過電流のしきい値（谷電流）は 6.1〜8.9 A。インダクタの飽和電流が、ピーク電流（約 9 A 以上）を上回るか、TDK のデータシートで確認する
2. **基板A↔B のピン 1 の向き**：基板A のピンヘッダは下向きに基板B の穴へ刺さる。PCB で、基板A の J_BA1 / J_BA2 のピン 1 と、基板B の J_AB1 / J_AB2 のピン 1 が重なるように配置する（片方は裏から見た配置になる）
3. テストパッド（`PWR_INT`、`L_PG`、主要な電源）を PCB で追加する
4. `VSYS` の入口（J_BA1 の近く）に、まとめのコンデンサを置くか（U3〜U6 の入力コンデンサで足りるかを PCB で判断）
5. mother-ring と MCU 基板側の回路は、KiCad から移植するときに、このピン配置に合わせて改版する
