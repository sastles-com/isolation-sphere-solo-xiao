# 実装担当（LLM / 技術者）への引き継ぎ

## 目的

本パッケージのアーキテクチャとインターフェースに従い、次世代 Isolation Sphere の電源サブシステムを EasyEDA で実装する。構成は 40 mm × 40 mm の PCB 2 枚の積層とする。

実装では、電池の安全性、予測可能な電源シーケンス、コンパクトなレイアウト、OFF 時の低消費電流、充電中の確実な動作を優先すること。

## 以下のアーキテクチャ決定を黙って変更しないこと

1. **40 × 40 mm の基板 2 枚**を使う。
2. **基板Aは上側のシステム電源 / mother-ring 基板。**
3. **基板Bは下側の電池 / 充電 / BMS 基板。**
4. 基板Bの裏面は LiPo パウチに面するため**部品禁止**。
5. **3.3 V 降圧コンバータを 2 個に分ける**。
   - LED レール
   - MCU レール
6. LED 降圧は ESP32 が `LED_EN` で制御する。
7. MCU システム電源は **LTC2954-1** が制御する。
8. 常時オンの磁気起動には **DRV5032FC**（DRV5032FCDBZR）を使う。
9. ~~TMAG5273 で磁気ジェスチャ~~ → 2026-10-10 に廃止。通常 OFF などのジェスチャは、MCU 基板の IMU（BNO055）によるシェイクで判定する。
10. 充電 / パワーパスは **BQ25792**（昇降圧、入力 5〜12 V、推奨 12 V。`hardware_spec.md` §3）。
11. パック残量計 / 保護は **BQ28Z620**（BQ28Z610-R1 の後継、ピン互換。`hardware_spec.md` §4）。
12. 旧構成の IP2326、XR-2S-30A、MP1584、MAX16054、MAX17049 は参考資料にとどめ、回路図の基本構成にはしない。
13. 基板Aは **1×6、2.54 mm ヘッダ 2 個**と `interfaces.md` の論理ネット割り当てで mother-ring に接続する。
14. 北極の WS2812C-2020-V6 は、XIAO の D5 から直接駆動する 6 本目のストリップ（1 個、電源 `3V3_MCU`）。2026-10-10 に `line05` の 161 番目から変更。
15. LED は **WS2812C-2020-V6** を使う（確定）。

データシートの要件により、確定事項のいずれかが電気的に実現不能または危険になる場合は、黙ってアーキテクチャを変えず、作業を止めて矛盾を報告すること。

## 第1作業：一次データシートでアーキテクチャを確認する

回路図を描く前に：

1. 以下の最新の公式データシート / テクニカルリファレンスマニュアルを読む。
   - LTC2954
   - DRV5032
   - BQ25792
   - BQ28Z620（データシートとテクニカルリファレンスマニュアル）
   - 選定した LED 降圧
   - 選定した MCU 降圧
   - WS2812C-2020-V6（電源電圧 3.3〜5.3 V を確認済み。`hardware_spec.md` §8.1）
2. 以下を確認する。
   - 電圧範囲
   - ロジックレベル
   - 起動 / 停止の要件
   - 充電器のパワーパス構成
   - BQ28Z620 の保護 FET 構成
   - 電流検出シャントの要件
   - セルタップ / BM の接続
   - I²C の電源ドメインでの挙動
3. 充電器 / システム経路が**パック保護を迂回しない**ように、充電 IC と BQ28Z620 の接続を正確に決める。
4. チャットのブロック図だけで回路図を実装できると考えないこと。

## 第3作業：回路図の作成

### 基板Aの回路図シート

推奨シート構成：

1. `A01_INPUT_VSYS`
2. `A02_LTC2954_POWER_CONTROL`
3. `A03_AON_3V3`
4. `A04_LED_BUCK_3V3`
5. `A05_MCU_BUCK_3V3`
6. `A06_MOTHER_RING_CONNECTORS`
7. `A07_BOARD_B_INTERFACE`
8. `A08_TEST_POINTS`

必要な動作：

- `LED_EN` はローカルでデフォルト OFF になる。
- MCU 降圧の EN は LTC2954 が制御するシステム状態に従う。
- MCU と LED のレールが OFF でも `3V3_AON` は維持される。
- 制御線から無効化したレールへ逆給電しない。
- `PWR_KILL` は `3V3_MCU` へプルアップする（ESP32 のリセットで電源が落ちないようにするため）。
- LTC2954 の INT はテストパッドへ引き出す（任意）。

### 基板Bの回路図シート

推奨シート構成：

1. `B01_LIPO_CELL_CONNECTIONS`
2. `B02_BQ28Z620_GAUGE_PROTECTION`
3. `B03_PROTECTION_FETS_SHUNT`
4. `B04_CHARGER_POWERPATH`
5. `B05_SOUTH_CHARGE_INPUT`
6. `B06_BOARD_A_INTERFACE`
7. `B07_NTC_AND_TEST_POINTS`

必要な動作：

- 保護は ESP32 から独立して自律的に働く
- 充電経路が保護を迂回しない
- 外部充電入力がある状態でもシステムが動作できる
- セル中点を正しく接続する
- シャントとケルビン検出は TI のレイアウトガイドに従う

## 第4作業：PCB レイアウト

### 基板Aのレイアウト優先度

1. 40 × 40 の機械形状に合わせて、まず mother-ring コネクタを配置する。
2. LED 降圧の電流ループを極力小さくする。
3. `3V3_LED_L` と `3V3_LED_R` を大電流出力として、それぞれのコネクタ側へ直接配線する。
4. MCU 降圧と I²C / 制御回路を、LED のスイッチングノードから離す。
5. LTC2954 / AON 回路を、ノイズの多いスイッチングノードから離す。
6. 連続した GND 基準面を使い、大電流の帰還経路を意図して制御する。

### 基板Bのレイアウト優先度

1. 裏面は部品なしを保つ。
2. 電池セル接続、シャント、FET、残量計の検出配線はリファレンスレイアウトに従う。
3. 充電器のスイッチングループを小さくする。
4. 充電器と保護 FET の熱を、可能な限り LiPo 側の面から離す。
5. LiPo 側へ鋭い突起を出さない。
6. 角を丸め、最終的な機械構成で絶縁フィルムを入れる。

## EasyEDA の自動化 / Python

Python が役立つ作業：

- BOM の生成
- ネット / インターフェースの整合性チェック
- ピン配置表
- 部品データベース / LCSC 対応表
- デザインルールのチェックリスト
- 電流 / 電力の計算
- 機械可読な設計仕様の生成

EasyEDA のプロジェクト JSON を**やみくもに生成しないこと**。EasyEDA Standard と EasyEDA Pro は内部形式が異なり、その形式は変わることがある。まず使う EasyEDA のエディション / バージョンを決め、最小のネイティブプロジェクトを書き出して中身を確認してから生成ツールを書くこと。

安全な進め方：

1. `design_spec.yaml` を正とする
2. Python で BOM / ピン配置 / 整合性レポートを生成する
3. 検証済みのライブラリ部品で EasyEDA に回路図を描く
4. テストプロジェクトで形式を確認した後に限り、EasyEDA ネイティブファイルの自動化を検討する

## 重要な未解決事項

推測で決めず、明示的に解決すること。

1. 充電 IC と BQ28Z620 の保護付きパワーパス構成の詳細。
2. 充電入力の供給方法（12 V アダプタか USB-PD トリガか）と、BQ25792 の入力電流上限（ILIM_HIZ）。
3. マグネット充電端子の電流定格、充電電流、入力電流制限。
4. 閉じた球体内で約 4 A を連続出力できる LED 降圧 IC とインダクタ。
5. MCU 降圧の電流目標（1 A か 1 A 超か）。
6. LED 降圧の出力電圧。WS2812C-2020-V6 の VDD 下限が 3.3 V のため、末端の電圧降下を見込んで 3.4〜3.5 V に設定する（`hardware_spec.md` §8.1）。
7. I²C プルアップのドメインと逆給電防止。
8. mother-ring コネクタの向き / 1 番ピンの規則。
9. 基板A ↔ 基板B のピン割り当て（案は `easyeda_workflow.md` §4.3）と、電池の電線の経路。

解決済み：

- EasyEDA Pro を使う。進め方は `easyeda_workflow.md`。
- 基板A ↔ 基板B の物理接続：PH-1x40SG ピンヘッダ + スペーサ。

- 残量計 IC（BQ28Z620）。
- 電池コネクタ（JST XH 2P × 2、セルごと。放電終止 6.4 V 以上）。
- 充電 IC（BQ25792）と充電入力電圧の方針（5〜12 V、推奨 12 V）。

- LTC2954 のバリアント（-1）、EN 極性、KILL 起動時の挙動、ONT / PDT の部品（`hardware_spec.md` §5）。
- DRV5032 のバリアント / 極性 / 出力形式（FC、`hardware_spec.md` §5）。磁石との距離の確認は残る。
