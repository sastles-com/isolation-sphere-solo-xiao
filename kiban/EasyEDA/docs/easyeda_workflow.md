# EasyEDA 設計の進め方

2026-10-08 に合意した方針。基板A / 基板B に加え、mother-ring と北極基板も EasyEDA Pro で作り直す。

## 1. 合意事項

| 項目 | 決定 |
| --- | --- |
| ツール | EasyEDA Pro。AI は `easyeda-api` スキルのブリッジ経由で操作する |
| 基板A / B | 1 つのプロジェクトに 2 枚のボードとして作る |
| mother-ring / 北極基板 | 作り直す。まず既存の KiCad データを EasyEDA Pro に移植し、その後で新しい電源仕様に合わせて改版する |
| 部品の配置 | **AI が行う**。人はゲート3で確認する |
| 基板A↔B 接続 | 秋月 PH-1x40SG（2.54 mm ピンヘッダ）を切って使い、スペーサで間隔を広げる（§4） |
| LiPo 接続 | JST PH コネクタを使う。基板には実装せず、ケーブルで引き出す（§5） |
| 製造 | JLCPCB の PCBA。4 層。基板Bは表面のみ実装、基板Aも収まれば表面のみ |
| Git | 各ゲートの節目で出力物をコミットする（§7） |

## 2. 役割分担

| 作業 | 担当 | 方法 |
| --- | --- | --- |
| 部品の取り込み、在庫確認 | AI | LCSC 番号から `lib_Device.getByLcscIds()` で取り込む |
| 回路図の部品配置とネット | AI | TI の評価ボード（EVM）の回路を写す。人がゲート2で確認 |
| ネットリストと仕様の照合 | AI | `sch_Netlist.getNetlist()` の出力を `design_spec.yaml` と Python で突き合わせる |
| PCB の部品配置 | AI | §6 の配置ルールに従い、座標を計算して配置する。人がゲート3で 3D 表示を確認 |
| 配線 | 未定 | 配置が固まった時点で決める |
| DRC、BOM / CPL / ガーバー出力 | AI | `pcb_Drc.check()`、`pcb_ManufactureData` |

EasyEDA のプロジェクトファイルを直接生成しない。すべて EasyEDA 上で API を通して操作する。

## 3. 段階と作業

| 段階 | 内容 | 終了条件 |
| --- | --- | --- |
| 0. 準備 | ブリッジ接続、プロジェクト作成、JLC 4 層の設計ルール、40 mm 角・角丸の外形、ヘッダ位置の決定 | — |
| 1. 部品の確定 | 残りの部品を選ぶ（LED / MCU 降圧、AON レギュレータ、保護 FET、シャント、BQ28Z610 の型番）。LCSC 在庫を確認 | ゲート1 |
| 2. 回路図 | 基板B（BQ25792EVM と BQ28Z610 EVM を写す）→ 基板A | ゲート2 |
| 3. 配置 | AI が配置し、電源ループと熱を確認 | ゲート3 |
| 4. 配線・検証・出力 | ERC / DRC、照合スクリプト、BOM / CPL / ガーバー | ゲート4 |
| 5. mother-ring / 北極 | KiCad から移植 → 新しいピン配置（3.3 V LED、1×6 ヘッダ）に改版 | 別途 |

### 3.1 先行事例の利用

`FPC-isolation-sphere/kiban/resized/power-2S-02/docs/` に、EasyEDA Pro を API で操作した実績と落とし穴がまとまっている。作業前に必ず読む。

- `07-easyeda-schematic-rules.md`：回路図のスタイル規約、座標と単位、API の実測上の注意
- `05-jlcpcb-fab.md`：JLCPCB 発注フロー、LCSC 部品選定ルール、実績のある LCSC 番号

主な注意点（同文書から抜粋）：

- 起動順は「ブリッジ → EasyEDA Pro」。逆にすると拡張が約 15 秒で接続をあきらめる。復旧はトップメニュー `API Gateway` → `Reconnect`
- EasyEDA Pro は Online モードで使う。半離線モードではクラウドのプロジェクトが 0 件に見える
- プロジェクト一覧の取得には `teamUuid` が必須
- 回路図の座標単位は 0.01 inch、PCB は 1 mil で、10 倍違う
- 回路図の矩形は、`create()` に渡す Y と `getAll()` が返す Y の符号が逆
- `modify()` は省略したフィールドを壊す
- ブリッジがタイムアウトしても、EasyEDA 側のスクリプトは走り続ける

回路図のスタイル規約（同文書 §1）も踏襲する。

1. 機能ブロックごとに矩形とタイトルで囲う
2. ブロック内はワイヤで直接配線する
3. ブロック間はネットポート（グローバルラベル）だけで接続する
4. GND はネットポートを使わず、ワイヤに `GND` ネット名を付ける

## 4. 基板A↔B 接続（ピンヘッダ + スペーサ）

### 4.1 使用部品

秋月 PH-1x40SG（<https://akizukidenshi.com/catalog/g/g100167/>）。必要なピン数に切って使う。

| 項目 | 値 |
| --- | --- |
| ピッチ | 2.54 mm |
| 絶縁体の高さ | 2.5 mm |
| ピン長 | 短い側 3.0 mm / 長い側 6.1 mm（全長 11.6 mm） |
| 定格電流 | 3 A / ピン |

### 4.2 組み方と間隔

ピンを基板Aに下から差し、短い側（3.0 mm）を基板Aにはんだ付けする。長い側（6.1 mm）を下へ伸ばし、基板Bのスルーホールに通す。
絶縁体と基板Bの間にスペーサ（厚さ s）を入れて間隔を広げる。

基板厚 1.6 mm として：

| スペーサ s | 基板間の間隔（2.5 + s） | 基板B裏面からのピン突出（4.5 − s） |
| ---: | ---: | ---: |
| 0 mm | 2.5 mm | 4.5 mm |
| 2.5 mm（絶縁体 1 枚分） | 5.0 mm | 2.0 mm |
| 4.0 mm | 6.5 mm | 0.5 mm |
| **4.5 mm** | **7.0 mm** | **0 mm（裏面と面一）** |
| 5.0 mm（絶縁体 2 枚分） | 7.5 mm | −0.5 mm（ピン先端が穴の中で止まる） |

- **推奨は s = 4.5 mm（間隔 7.0 mm）**。ピン先端が基板B裏面と面一になり、LiPo 側に突起が出ない。
- s = 5.0 mm（ヘッダの絶縁体を 2 枚重ねる）でもよい。ピンは基板B（1.6 mm）に 1.1 mm 入るので、はんだはスルーホールを埋めて接合する。
- 基板Bのはんだ付けは裏面（LiPo 側）から行う。はんだの盛り上がりを平らにし、絶縁フィルムで覆う。
- 間隔 7.0 mm なら、基板B表面の部品と基板A裏面の部品の高さの合計を 6 mm 程度まで使える（クリアランス 1 mm を残す）。BQ25792 のインダクタ（高さ 2〜3 mm 級）は収まる。

### 4.3 ピン割り当て案

基板Aの左右の辺は mother-ring コネクタが使う。基板A↔B のヘッダは、残りの前後 2 辺に 1 本ずつ置く。2 本に分けるのは、積み重ねたときの機械的な安定のため。

| ピン | J_AB1（電源） | J_AB2（信号） |
| ---: | --- | --- |
| 1 | `VSYS` | `I2C_SDA` |
| 2 | `VSYS` | `GND` |
| 3 | `VSYS` | `I2C_SCL` |
| 4 | `GND` | `CHG_INT`（BQ25792 INT、オープンドレイン） |
| 5 | `GND` | 予備 |
| 6 | `GND` | `GND` |

- `VSYS` は 3 ピン並列。最大約 3.1 A を 1 ピンあたり約 1.0 A に分ける（定格 3 A）。
- I²C の間に `GND` を挟み、クロストークを減らす。
- `CHG_INT` は `interfaces.md` §3 の `BATT_INT`（任意）に相当する。ESP32 側に GPIO を割り当てるかは未定。

## 5. LiPo 接続（JST PH、ケーブル引き出し）

### 5.1 方針

基板BにはJST PHを実装せず、はんだ付けパッドから電線を引き出し、その先に PH コネクタを付けて電池と接続する。

基板に実装しない理由：

- 基板上の面積を節約できる（上面実装の B3B-PH-K でも約 8.0 × 4.5 mm、横向きの S3B-PH-SM4-TB では約 10 × 10 mm を占める）
- 高さが収まらない。嵌合した PH の高さは 10 mm 前後あり、基板間隔 7.0 mm（§4.2）を超える

### 5.2 基板B側の配線パッド

| パッド | ネット | 電線 |
| --- | --- | --- |
| BAT+ | `B+` | AWG22（最大約 3.1 A） |
| BAT_M | `BM`（セル中点） | AWG26〜28（検出用、電流は小さい） |
| BAT− | `B−` | AWG22 |
| NTC（任意） | 電池の温度センサ | 電池に付いている場合のみ |

- パッドは基板B表面の端に並べる。電線のはんだ付けと引き回しのため、パッドの外側に部品を置かない。
- 大きさの目安は 3 パッドで約 10 × 6 mm（パッド Φ2 mm、ピッチ 3 mm、ひずみ逃がし穴付き）。
- 電線が LiPo 側へ回り込まないよう、引き出し方向を基板の外側へ向ける。

### 5.3 確認が必要な事項（重要）

1. **電流定格**：JST PH の定格は 1 ピンあたり 2 A（AWG24）。本設計の電池電流は全負荷で最大約 3.1 A（6.0 V 時）になり、**定格を超える**。対策は次のいずれか。
   - B+ と B− をそれぞれ 2 ピン並列にする（例：5 ピンの PH で B+ / B+ / BM / B− / B−）
   - 電源線は 3 A 級のコネクタ（例：JST XH 2.5 mm）にし、PH はバランス線（BM）だけに使う
   - ファームで LED 電流を制限し、電池電流を 2 A 以下に抑える（LED 約 2.3 A まで。明るさが落ちる）
2. **電線同士をつなぐ PH**：JST PH は基板用の製品で、電線同士をつなぐ純正品はない。電池側の PHR ハウジングと嵌合させるには、互換品のオスプラグ（電線付き）を使うか、小さな中継基板に PH ヘッダを載せる必要がある。
3. **嵌合部の置き場所**：3 ピンの PH を嵌合させると、約 8 × 4.5 × 13 mm（電線の曲げを除く）の空間が要る。コアの開口は約 40〜42 mm 角で、40 mm 角の基板の周囲にはほとんど余裕がない。
   電池（2000 mAh、約 50 × 35 × 10 mm × 2）の向きとコア内部の寸法から、置き場所を決める必要がある。現時点では寸法データがなく、**確保できるかは判断できない**。

## 6. AI による部品配置のルール

1. 外形、取り付け位置、コネクタ（mother-ring 用、基板A↔B 用、電池パッド）を最初に固定する。
2. 電源 IC は、評価ボードのレイアウトにある部品の相対位置を写す。入力コンデンサ → IC → インダクタ → 出力コンデンサの電流ループを最小にする。
3. 発熱部品（LED 降圧とインダクタ、BQ25792 とインダクタ、保護 FET、シャント）は互いに離し、基板B中央（LiPo パウチ中央の真上）を避ける。
4. ノイズに弱い回路（LTC2954、AON レギュレータ、I²C、BQ28Z610 の検出線）はスイッチングノードから離す。
5. 部品の高さを確認する。基板B表面と基板A裏面の部品高さの合計は、基板間隔から 1 mm 引いた値以下にする。
6. 配置案ごとにスクリーンショット（上面、下面、3D）を出し、ゲート3で人が確認する。

## 7. Git での管理

EasyEDA Pro の設計本体はクラウドに置く。各ゲートの節目で、以下を `kiban/EasyEDA/` にコミットする。

| フォルダ | 内容 |
| --- | --- |
| `project/` | プロジェクトのバックアップ（.epro） |
| `outputs/` | 回路図 PDF、ネットリスト、BOM、CPL、配置のスクリーンショット |
| `tools/` | 照合用の Python スクリプト |

レビューでは主に PDF とネットリストの差分を見る。
